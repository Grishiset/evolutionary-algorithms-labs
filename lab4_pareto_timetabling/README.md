# Лабораторная работа № 4 — многокритериальное расписание с интерактивным выбором из фронта Парето (вариант 8)

Недельное расписание: 80 занятий, 8 групп, 12 преподавателей, 9 аудиторий. Жёсткие ограничения, три конфликтующих критерия.
Сравниваются NSGA-II, меметический NSGA-II и взвешенная свёртка (по 30 запусков при равном бюджете). Найденный фронт экспортируется в автономную HTML-страницу для выбора расписания.

| Документ | Содержание |
|---|---|
| [PROPOSAL.md](PROPOSAL.md) | заявка на тему: постановка, представление, алгоритмы, данные, критерии, риски |
| [REPORT.md](REPORT.md) | отчёт: модель, алгоритмы, 30 запусков, статистика, анализ, ограничения |
| [DEMO.md](DEMO.md) | сценарий демонстрации на 5–7 минут |
| [results/pareto_viewer.html](results/pareto_viewer.html) | **интерактивный выбор расписания** — открыть в браузере, сеть не нужна |

## Запуск

```bash
python -m pip install -r ../requirements.txt
python generate_data.py                  # данные уже в data/instance.json; пересоздание даёт тот же файл
python run_experiments.py --workers 2    # 3 алгоритма × 30 запусков, бюджет 100 000, ~6 мин на 2 ядрах
python build_viewer.py                   # results/front.json -> results/pareto_viewer.html
python choose.py                         # консольный выбор: пороги и веса спрашиваются в диалоге
python choose.py --max 3 1.5 40 --weights 1 2 1 --group 2 --teacher 4
python -m pytest -q tests
```

## Файлы

| Файл | Назначение |
|---|---|
| `generate_data.py` | генератор экземпляра (seed 2026), процедура описана в docstring |
| `timetable.py` | модель: векторизованная оценка критериев и нарушений, декодер аудиторий, вывод расписания |
| `moea.py` | NSGA-II, меметический локальный поиск, взвешенная свёртка, HV, IGD |
| `run_experiments.py` | серии запусков, статистика ($p$, $A_{12}$), графики, экспорт фронта |
| `build_viewer.py` | генерация автономной HTML-страницы выбора |
| `choose.py` | консольный выбор решения |
| `config.json` | параметры алгоритмов |
| `results/` | `runs.csv` (каждый запуск с его фронтом), `summary.csv/.md`, `front.json`, `representative.md`, графики |
