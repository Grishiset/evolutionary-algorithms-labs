## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt

# все тесты (около 10 с)
for d in lab1_zakharov lab2_student_projects lab3_synthesis/track_a_ev_charging \
         lab3_synthesis/track_b_vacuum_fsm lab4_pareto_timetabling; do (cd $d && python -m pytest -q tests); done
```

Как запускать эксперименты каждой работы, описано в её `README.md`. Все результаты в папках `results/` получены этими скриптами с указанными seed и воспроизводятся повторным запуском. Проверено на Python 3.13, Linux.

## Общие принципы

* **Воспроизводимость.** Каждый запуск принимает `--seed`. Серии экспериментов используют seed 1…N (`--runs`, `--seed0`), синтетические данные генерируются с фиксированным seed и лежат в репозитории.
* **Серии запусков.** 30 запусков в ЛР 1, 2 и 4, 20 — в ЛР 3. Отчёты приводят лучшее, среднее, медиану, стандартное отклонение и худшее, сравнения сопровождаются критерием Манна–Уитни.
* **Параметры алгоритмов** заданы явно в `config.json` каждой работы и дублируются в `results/*config*.json` вместе со списком seed.
* **Честные сравнения.** Все алгоритмы в одном сравнении получают одинаковый бюджет вычислений фитнес-функции. Где это важно, отдельно учтено и время работы.
* **Отрицательные результаты** не скрываются: гипотезы, которые не подтвердились, описаны в отчётах вместе с причинами.
