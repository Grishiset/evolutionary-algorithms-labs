# Лабораторная работа № 1 — ГА для функции Захарова (вариант 8)

Многомерная непрерывная оптимизация вещественным генетическим алгоритмом.
Функция Захарова, размерность `d = 5 + (8 mod 6) = 7`, область `[-5, 10]^7`, минимум `f(0) = 0`.

Отчёт: [REPORT.md](REPORT.md).

## Установка

```bash
python -m pip install -r ../requirements.txt     # numpy, matplotlib, scipy, pytest
```

Проверено на Python 3.13. Подойдёт Python 3.10 и новее.

## Запуск

```bash
# один прогон с параметрами из config.json и заданным seed
python ga.py --seed 19

# полная серия экспериментов (30 запусков на конфигурацию, seed = 1..30), около 30 с
python run_experiments.py

# другая серия seed и другая папка результатов
python run_experiments.py --runs 20 --seed0 100 --out results_seed100

# тесты
python -m pytest -q tests
```

Повторный запуск `run_experiments.py` с теми же аргументами даёт те же числа в `results/`.

## Файлы

| Файл | Назначение |
|---|---|
| `zakharov.py` | целевая функция, границы, гессиан в оптимуме |
| `ga.py` | ГА: селекция (турнир / ранговая / рулетка с масштабированием), кроссовер (SBX / BLX-α / арифметический), гауссовская мутация с адаптацией σ по правилу 1/5, отражение от границ, элитизм |
| `baselines.py` | случайный поиск и локальный поиск с фиксированным шагом при том же бюджете |
| `run_experiments.py` | все обязательные эксперименты, таблицы и графики |
| `config.json` | базовые параметры алгоритма |
| `results/runs.csv` | итог каждого запуска: конфигурация, seed, f, x, время |
| `results/summary.csv`, `results/summary.md` | статистика по сериям |
| `results/experiments_config.json` | полный набор параметров каждой конфигурации и список seed |
| `results/*.png` | графики сходимости, сравнения и адаптации σ |
