# Лабораторная работа № 3 (трек A) — NSGA-II: планирование зарядки электромобиля (вариант 8)

Три критерия: минимум стоимости, минимум пикового потребления дома, максимум итогового заряда.
NSGA-II реализован самостоятельно: быстрая недоминируемая сортировка, расстояние скопления, доминирование с ограничениями, SBX, полиномиальная мутация. Для сравнения есть ГА со взвешенной суммой и точный гиперобъём.

Отчёт: [REPORT.md](REPORT.md).

```bash
python -m pip install -r ../requirements.txt
python run_experiments.py                  # 5 алгоритмов × 20 запусков (seed 1..20), ~4 мин
python run_experiments.py --runs 30 --seed0 100 --out results_alt
python -m pytest -q tests
```

| Файл | Назначение |
|---|---|
| `model.py` | модель: тариф, базовая нагрузка, декодер (ремонт по лимиту сети, ограничение заряда), критерии, LP-ориентиры, мутация «перенос энергии» |
| `nsga2.py` | NSGA-II, ГА со взвешенной суммой, недоминируемая фильтрация, точный гиперобъём (2D/3D) |
| `run_experiments.py` | серии запусков, статистика, характерные решения, графики |
| `config.json` | параметры алгоритмов |
| `results/` | `runs.csv`, `summary.csv/.md`, `best_front.csv` (фронт с профилями зарядки), графики |
